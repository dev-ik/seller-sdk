# История изменений

Значимые изменения Seller SDK фиксируются в этом файле.

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## Не выпущено

### Улучшено

- Добавлены генерируемые из Ozon Swagger пояснения значений `OzonValues` в
  IntelliSense.

## 0.1.0 — 2026-08-16

### Добавлено

- Полный типизированный Ozon domain API, сгенерированный из проверенного
  endpoint manifest.
- 461 операция Ozon и рекомендуемые алиасы без версий с сохранением явных
  версионных методов.
- IntelliSense-документация и `OzonValues` для закрытых наборов значений.
- Настройки тайм-аутов, дедлайнов, отмены и повторов на уровне клиента и запроса.
- Безопасные сообщения API-ошибок и метаданные каждого HTTP-ответа.
- Ленивая пагинация товаров, FBO и FBS, а также общие pagination helpers.
- Fixed-origin `rawRequest` для новых операций Ozon до обновления SDK.
- SafeShape-валидация ответов и стабильные типы ошибок Seller SDK.
- Отдельный пакет `@seller-sdk/ozon` и общий пакет `seller-sdk`.

### Безопасность

- Мутации не могут быть повторены настройкой retry.
- Credentials, authorization headers и необработанные тела ответов исключены из
  SDK-ошибок.
- URL запросов ограничен фиксированным origin Ozon Seller API.
