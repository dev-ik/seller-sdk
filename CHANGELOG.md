# История изменений

Значимые изменения Seller SDK фиксируются в этом файле.

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## Не выпущено

## 0.2.1 — 2026-08-17

### Улучшено

- README npm-пакетов дополнены прямыми ссылками на руководства и API Reference,
  а также отдельными пояснениями о независимости проекта от Ozon и
  Wildberries.
- Workflow публикации теперь автоматически создаёт GitHub Release и прикладывает
  tarball каждого опубликованного пакета.

## 0.2.0 — 2026-08-17

### Добавлено

- Самостоятельный пакет `@seller-sdk/wb` и `Marketplace.Wb` в umbrella registry.
- 286 типизированных операций из 13 официальных OpenAPI-разделов Wildberries.
- 282 рекомендуемых WB-алиаса без версии с сохранением точных имён операций из
  Swagger.
- `WbValues` со значениями закрытых строковых enum/union и документацией для
  автодополнения TypeScript.
- SafeShape-контракты ответов, production/sandbox routing и fixed-origin
  `rawRequest` для WB.
- Единый `toSellerSdkErrorDetails()` для безопасного представления ошибок Ozon,
  Wildberries и umbrella-пакета.

### Улучшено

- Добавлены генерируемые из Ozon Swagger пояснения значений `OzonValues` в
  IntelliSense.
- Для Ozon и Wildberries исправлена генерация `@deprecated`: вложенные поля
  больше не помечают весь метод, а реальные устаревшие операции содержат
  рекомендуемую замену.
- Документация маркетплейсов разделена между focused-пакетами; общий README
  содержит ссылки на отдельные руководства и API Reference.

## 0.1.0 — 2026-08-16

### Добавлено

- Полный типизированный Ozon domain API, сгенерированный из проверенного
  endpoint manifest.
- 461 операция Ozon и рекомендуемые алиасы без версий с сохранением явных
  версионных методов.
- IntelliSense-документация и `OzonValues` для закрытых наборов значений.
- Настройки тайм-аутов, дедлайнов, отмены и повторов на уровне клиента и запроса.
- Безопасные сообщения API-ошибок и метаданные каждого HTTP-ответа.
- Ленивая пагинация товаров, FBO и FBS, а также общие pagination helpers.
- Fixed-origin `rawRequest` для новых операций Ozon до обновления SDK.
- SafeShape-валидация ответов и стабильные типы ошибок Seller SDK.
- Отдельный пакет `@seller-sdk/ozon` и общий пакет `seller-sdk`.

### Безопасность

- Мутации не могут быть повторены настройкой retry.
- Credentials, authorization headers и необработанные тела ответов исключены из
  SDK-ошибок.
- URL запросов ограничен фиксированным origin Ozon Seller API.
