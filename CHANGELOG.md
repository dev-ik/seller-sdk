# История изменений

Значимые изменения Seller SDK фиксируются в этом файле.

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## Не выпущено

## 0.4.0 — 2026-10-19

### Несовместимые изменения Ozon

- Алиасы `createFbsPackageLabelBatch`, `getFbsPackageLabelBatch`, методы
  автодобавления в акции без суффикса версии и `products.pictures.import`
  переключены на новые контракты Ozon. Обновите обработку ответов этикеток,
  денежные поля акций и запрос импорта изображений.
- `delivery_schema` в фильтре отчёта отправлений теперь обязателен. Из типов
  и `OzonValues.CertificateAccordanceType` удалены `TECHNICAL_REGULATIONS_RF`,
  `TECHNICAL_REGULATIONS_CU` и `GOST`.
- Тип ответа списка уведомлений включает обязательные поля мониторинга
  доступности из текущего OpenAPI; обновите собственные fixtures и моки.
- Порядок перехода с `0.3.x` описан в
  [руководстве по миграции](docs/ozon/MIGRATION-2026-10.md).

### Ozon

- Добавлены 11 официальных замен для этикеток, акций и импорта изображений
  по предоставленному OpenAPI от 19 октября 2026; старые явные методы сохранены.
- Алиасы этикеток, автодобавления в акции и `products.pictures.import` используют
  новые версии с собственными request/response types и SafeShape-контрактами.
- Добавлены `total_items`, `declared_price`, `scanit`, новые ошибки поставок,
  фильтры и мониторинг доступности push-уведомлений; сохранён options-only вызов
  списка уведомлений.
- Синхронизированы request-поля складов, фильтр видимости товаров и enum
  сертификатов. `delivery_schema` в отчёте отправлений теперь обязателен.
- Исправлено ложное определение устаревшего метода по предупреждению об
  устаревшем поле. Две отсутствующие в новом snapshot операции `quant` сохранены
  отдельно с архивным происхождением.
- Изменения форм вызовов и ограничения покрытия описаны в
  [руководстве по миграции](docs/ozon/MIGRATION-2026-10.md).

### Состав выпуска

- Все четыре npm-пакета выпускаются с общей версией `0.4.0`. Контракты
  Wildberries и Yandex Market в этом выпуске не менялись.
- SDK содержит 472 метода Ozon: 470 операций текущего snapshot и 2 архивные.
  Ещё 13 новых операций Ozon остаются вне этой миграции; полного обновления
  всех полей ответов этот выпуск не заявляет.

## 0.3.2 — 2026-09-10

### Улучшено

- `@safe-shape/core` обновлён с 2.0.0 до 3.0.0 в focused-пакетах,
  umbrella-пакете и workspace. Публичные типы ошибок Seller SDK и политика
  совместимости ответов сохранены.
- Ручной парсер дерева категорий Ozon адаптирован к обязательному `severity`
  в SafeShape 3; добавлены проверки некорректной структуры дерева и путей ошибок.
- Обычный CI проверяет метаданные без запроса к npm; проверка занятости версии
  остаётся обязательной в `release:check` и `prepare:release`.
- Отдельное задание CI проверяет типы, тесты и сборку с минимальной заявленной
  версией SafeShape на минимальной поддерживаемой версии Node.js.

## 0.3.1 — 2026-08-19

### Документация

- README `@seller-sdk/ym` дополнен полным руководством по аутентификации,
  идентификаторам кабинета и магазина, всем областям API, `YmValues`,
  пагинации, тестовым заказам, бинарным ответам, ошибкам и `rawRequest`.
- В корневой README добавлен основной пример конфигурации и вызова Yandex
  Market наравне с Ozon и Wildberries.

## 0.3.0 — 2026-08-19

### Добавлено

- Самостоятельный пакет `@seller-sdk/ym` со всеми 165 операциями официального
  Yandex Market Partner API snapshot.
- `Marketplace.Ym`, литерал `"ym"` и строго типизированный `seller.ym` в
  umbrella-пакете.
- Генерируемые YM types, SafeShape-контракты, `YmValues`, API reference и
  metadata deprecation/rate limits.

### Улучшено

- `@safe-shape/core` обновлён до 2.0.0 во всех marketplace-пакетах.
- Рекурсивные YM-контракты `RegionDTO` и `CategoryDTO` используют SafeShape
  `lazy` без ограничения глубины.
- Transport поддерживает marketplace-specific разбор вложенных API-ошибок и
  YM rate-limit status 420.
- Ключи `YmValues` нормализованы в PascalCase, JSDoc очищен от внутренних
  шаблонных директив, а поведение методов без суффиксов версии явно описано.

## 0.2.1 — 2026-08-17

- README npm-пакетов дополнены прямыми ссылками на руководства и API Reference,
  а также отдельными пояснениями о независимости проекта от Ozon и

## 0.2.0 — 2026-08-17

### Добавлено

- Самостоятельный пакет `@seller-sdk/wb` и `Marketplace.Wb` в umbrella registry.
- 286 типизированных операций из 13 официальных OpenAPI-разделов Wildberries.
- 282 рекомендуемых WB-алиаса без версии с сохранением точных имён операций из
  Swagger.
- `WbValues` со значениями закрытых строковых enum/union и документацией для
  автодополнения TypeScript.
- SafeShape-контракты ответов, production/sandbox routing и fixed-origin
  `rawRequest` для WB.
- Единый `toSellerSdkErrorDetails()` для безопасного представления ошибок Ozon,
  Wildberries и umbrella-пакета.

### Улучшено

- Добавлены генерируемые из Ozon Swagger пояснения значений `OzonValues` в
  IntelliSense.
- Для Ozon и Wildberries исправлена генерация `@deprecated`: вложенные поля
  больше не помечают весь метод, а реальные устаревшие операции содержат
  рекомендуемую замену.
- Документация маркетплейсов разделена между focused-пакетами; общий README
  содержит ссылки на отдельные руководства и API Reference.

## 0.1.0 — 2026-08-16

### Добавлено

- Полный типизированный Ozon domain API, сгенерированный из проверенного
  endpoint manifest.
- 461 операция Ozon и рекомендуемые алиасы без версий с сохранением явных
  версионных методов.
- IntelliSense-документация и `OzonValues` для закрытых наборов значений.
- Настройки тайм-аутов, дедлайнов, отмены и повторов на уровне клиента и запроса.
- Безопасные сообщения API-ошибок и метаданные каждого HTTP-ответа.
- Ленивая пагинация товаров, FBO и FBS, а также общие pagination helpers.
- Fixed-origin `rawRequest` для новых операций Ozon до обновления SDK.
- SafeShape-валидация ответов и стабильные типы ошибок Seller SDK.
- Отдельный пакет `@seller-sdk/ozon` и общий пакет `seller-sdk`.

### Безопасность

- Мутации не могут быть повторены настройкой retry.
- Credentials, authorization headers и необработанные тела ответов исключены из
  SDK-ошибок.
- URL запросов ограничен фиксированным origin Ozon Seller API.
